### 2. python-expert
**Scope:** Core scanner code quality and graceful degradation

**Tasks:**
1. Audit `medusa/scanners/*.py` for tool dependencies
2. Replace hard failures with graceful skips
3. Add proper logging for skipped tools
4. Update banner in `medusa/cli.py`

**Pattern to implement:**
```python
# Before (hard failure)
if not shutil.which('bandit'):
    raise RuntimeError("bandit not found")

# After (graceful skip)
if not shutil.which('bandit'):
    logger.debug("bandit not installed, skipping bandit scanner")
    return []
```

**Files:**
- `medusa/scanners/*.py` (all scanner files)
- `medusa/cli.py` (banner section)
- `medusa/__init__.py` (version bump)
